# ZIVOPO

ZIVOPO is a premium super app platform for verified human assistance, student gigs, corporate concierge, senior support, and community services.

## Monorepo structure

- apps/web: Next.js marketing and customer web experience
- services/api: NestJS backend API with Swagger and health endpoints
- apps/mobile: Flutter mobile app foundation
- docs: architecture and deployment documentation

## Quick start

1. Install web deps: npm run install:web
2. Install API deps: npm run install:api
3. Start web: npm run dev:web
4. Start API: npm run dev:api
